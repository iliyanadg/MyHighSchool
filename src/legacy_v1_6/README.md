# Base v1.6 — sorgenti selezionati

`mhs_registry.py` è una copia **esatta** del modulo originale tratto dall'archivio del progetto condiviso.

Questo file non è una mod installabile e da solo non gestisce l'aula fisica. È stato isolato per cominciare a eseguire test offline del registro in un ambiente controllato. Gli altri moduli della v1.6 rimangono nell'archivio sorgente conservato dall'utente, senza modifiche.

**Non compilare o installare automaticamente questo materiale nel gioco.**
