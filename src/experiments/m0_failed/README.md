# M0: esperimento fallito, NON installare

Questi sei XML sono copie testuali degli originali nel pacchetto M0 inviato e provato il 30 ottobre 2026. Il package associato impediva l'avvio di The Sims 4; rimosso il file, il gioco ripartiva.

**Il difetto esatto non è ancora dimostrato.** Una differenza riscontrata rispetto a Sonozaki è l'assenza della risorsa SimData associata alla categoria del menu. Questo è un indizio, non una spiegazione conclusiva.

Non ci sono build installabili in questo repository. Non usare questi XML per creare un nuovo package senza riesaminare le risorse EA e le dipendenze.
